# v1.0「niulai」评审决策存档

> 本文档只保留评审的**最终结论**；问题明细与修复过程见 v1.0.0 tag 之前的 git 历史。

## 决策记录

- **第三次结转**：不做硬拦截，`carryCount >= 2` 仅触发强制复盘提示。
- **任务大厅**：「需求池」更名为任务大厅，条目是**委托**（需求在外部流程管理）；委托可编辑、可解除关联、三态由关联任务自动推导；Epic 委托不可直接上车（前后端双拦截）。
- **稀有度分级**：按 `docs/任务大厅与稀有度分级设计方案.md`（已定稿）在 v1.1 实施；v1.0 不落地。
- **班次模型**：「淡化周概念、单月多班车」重构留待后续版本；v1.0 仅支持送达日期手工补录。
- **等量换出**：不进入工具，保留为发车会纪律。

## 发版后跟进项

- Docker 镜像本机未实测，构建正确性由 CI `docker` job 保证。
- `db:seed` 对从未启动过的全新库不自愈（不建表），需先启动过一次服务。
