## 一、要验证什么（写在前面的成功标准）

灵魂文档假设 H5 + 第六节基线指标，纸面 4 班结束时按这些数据说话：

| 指标               | 观察什么                                        | 稳态长什么样                     |
| ------------------ | ----------------------------------------------- | -------------------------------- |
| 储备消耗率         | 每班预留储备被急件消耗的比例                    | 既不用罄也不长期闲置             |
| 让位自愿率         | 让位件中自愿（非指派）占比                      | **100%——出现一次指派即毒性信号** |
| 保座兑现率         | 让位件在下一班是否如期上车且未被再次让出        | 100%                             |
| 急件绕过率         | 未走议价台的急件占比（任何人可补录）            | 趋降                             |
| "为什么是现在"命中 | 周五审计三问中该理由成立的占比                  | 趋升（急的含金量被校准）         |
| 债务健康度         | 跨班借贷余额走势                                | 有借有还，不单调增长             |
| 预测参与率与命中   | 下注人数 / 全员；命中分布（全员含 PM）          | 参与率 ≥50%，校准随班次改善      |
| 治理耗时           | 议价台流程给周五会增加的分钟数（预算 +15 分钟） | ≤15 分钟                         |

**退出阀（红线 6）**：纸面运行满 4 班必须复盘去留；毒性信号触发即回退（见第六节）。

## 二、谁上桌（决议 6 · 博弈主体上移）

- **议价台出席者**：PM / 领导 / 开发负责人三方。普通开发**不参与议价**——开发个人与系统之间只有自己的件、自己的承诺、周五的 demo。
- 让位邀请面向全员（谁自愿谁举手），但**补偿谈判由开发负责人代表团队**；内部如何分派是开发侧自治，纸面与工具都不介入。
- **记录人**（纪要模板里的记录人兼任）：手写议价单、维护让步总账、开奖预测投票、补录绕过件——纸面运行的"系统"就是记录人的笔记本 + 纪要。
- 领导在系统里就是**一位提出人**：急件照常录快件、`requester` 填领导标签、`source` 选 customer——记分卡自动覆盖，问责沿权力线走。

## 三、议价台七构件 · 纸面形态

### 3.1 领导储备（surge reserve）

- **规则**：每班发车时装载**预留 4 点不排产**（全班公共容量，不是某人的）。急件优先消耗储备——"临时插入"从"对计划的破坏"变成"对预算内缓冲的使用"。
- 储备**周四仍未用则留白**（早收工/呼吸空间），**不自动回填需求**——防帕金森定律。
- **纸面动作**：发车段装载完毕后，记录人在纪要写"本班储备 4 点"；周中每用一次减一次。
- 参数（储备额、准点率赌题线等）见第七节参数表，复盘会多数同意可改。

### 3.2 急件议价单（deal card + win-set 菜单）

- **触发**：周中领导提出急件（照常 1~10 点 + 一句**"为什么是现在"**——这句必填，周五审计要回看）。
- **纸面动作**：记录人十分钟内手写一张议价单（模板见附录 A），列出 2~4 个**打包方案**，领导选其一：
  - **方案 A · 吃储备**：储备余量 ≥ 急件点数，直接上；
  - **方案 B · 让位**：某成员自愿把本班件换乘下一班 + 保座票 + 滞留豁免 + 让位点数记账（急件 + 换出项 + 补偿一体呈现，一次谈一揽子）；
  - **方案 C · 借贷**：预支下一班容量，记明账债务，下一班发车段第一项议程还债；
  - **方案 D · 加开一班**：现有「发新车」动作，零开发零流程（注意红线：**加班车不得连续两班**，第二班仍需加班即触发强制复盘）。
- **两条铁律**：
  1. **菜单永不空**——总有一条路可走，没有人需要说"不"，但每个人都必须选；
  2. **默认规则 = 维持现状**——谈不成时急件转下一班候选，**不是急件默认赢**。领导的权力是选菜单的权力，不是豁免权。
- 急件本身照常录入系统（快件表新增即可），装载超建议上限只是提示不拦截，与本工具哲学一致。

### 3.3 自愿让位（voluntary bumping）

- **规则**：需要腾位时发"让位"邀请，**只邀不派**。补偿三件套：
  1. **保座票**：下一班必上（系统侧已由"结转=转紧邻下一班"物理保证，纸面只需跟踪下一班**不把它再次让出/结转**）；
  2. **让位点数记账**：进让步总账（积分补偿属冻结区，纸面期以让位点数作为互惠凭证）；
  3. **滞留豁免**：让位是"换乘"不是"滞留"——不计个人滞留、不递增复盘义务（纸面期的落地约定见第五节）。
- 自愿者自选成本最低者；**无人自愿就走借贷或加开，绝不指派**。
- 换出尽量**等量**（Change for Free：变更永远免费，但交换永远必须）；不等量部分由补偿条款找平。

### 3.4 跨班借贷（inter-van borrowing）

- **规则**：本班装不下而领导仍要 → 预支下一班容量，记明账债务；**没有限额——账本就是限额**（债务全队可见、自己管理）。
- **纸面动作**：纪要"还债清单"栏记账（班次、点数、事由）；**下一班发车段第一项议程**过还债清单——债务对应的保座件优先装载。
- 债务健康度进 Gate 2 数据（连续 2 班只借不还触发复盘提示）。

### 3.5 契约工具箱（让妥协可信）

议价单上的条款勾选区，四件现成模板：

- **保座票**：下班必上（默认必选）；
- **探针先行**：本周 1~2 点验证、下班全量（对应设计方案"探针任务"）；
- **分期**：跨班切片交付；
- **对赌条款**："若周五未送达则 \_\_\_"（写清后果，别留口头）。

### 3.6 周五急件审计（ex-post accountability）

验收段对本周每件急件过**三问**（纪要"急件审计"栏，逐件一行）：

1. 送达了吗？（系统二值数据，不吵架）
2. "为什么是现在"当时成立吗？
3. 值吗？（一句话）

急件计入提出人记分卡——领导与 PM 接受同样的记分。事前不拦（免审批摩擦），事后必审（校准"急"的含金量）；命中率长期偏低时，记分卡替团队说话。

### 3.7 让步总账（reciprocity ledger）

纪要固定栏位，按班滚动：**让位点数、债务余额、保座兑现率**。让步被记住，合作才可持续；不平衡要在游戏内被看见并在游戏内再平衡，而不是积累成游戏外的怨气。

## 四、预测投票（Futarchy-lite 纸面版）

- **下注时点**：周五会**发车段**，新班发出后立即进行。
- **赌题**：「本班送达率 ≥ 80%？」（送达率 = 统计条「送达率」读数，即 `completionRate = done / total`，v1 done 口径按件；80% 为初始参数，复盘会可调）。
- **玩法**：每人写下「≥ / ＜」+ 自己的名字交给记录人，**开奖前不公开他人下注**；全员含 PM——装出来的好结果要先骗过下注的自己（决议 2 交叉验证）。
- **开奖**：下一周五**验收段**，记录人按统计条「送达率」公布命中名单；**连续 3 班命中**手工累计「🔮 预言家」连击（工具化后自动成徽章，纸面期记在纪要）。
- 预测的赌题对象是共同结果，不是任何个人的件——对事不对人（决议 5）。

## 五、与现有系统的咬合约定（纸面期最重要的操作纪律）

纸面期系统零改动，以下约定让纸面流程与既有规则互不踩踏，**并保证 Gate 2 工具化时数据可回溯**：

1. **周中只谈、周五落账**：急件周中照常录入本班（超载仅提示）；让位件的「结转」操作**统一推迟到周五会现场执行**。原因：系统规则是**结转即归档只读**（源班存在 carried 任务整班锁定），周中执行会让整班无法编辑；周五本来就是关班结转的时点，天然吻合。
2. **让位件的系统记录**：结转原因选 `priority`（优先级被挤），**note 以 `swap：` 开头**并写明为哪件急件腾位（例：`swap：为急件「DV2609A/优惠券风控」让位`）。这是纸面期的 swap 标记约定——Gate 2 工具化引入 `carryReason='swap'` 枚举时，凭 `swap：` 前缀可靠回溯补录。
3. **滞留口径人工剔除**：系统统计（滞留率、滞留原因瀑布）暂含让位件，记录人朗读与判定时**人工剔除 note 带 `swap：` 的件**；已知噪声，Gate 2 落库 swap 枚举后消除。
4. **carryCount 豁免**：让位件照常递增系统 carryCount，若触发「强制复盘提示」，会上按"让位豁免"说明即可——提示不拦截，无碍。
5. **保座票的物理实现**：结转动作已把件放进紧邻下一班（保座已成立），纸面只需跟踪**下一班不再让它二次让出**——被再次让出即保座违约，记入让步总账。
6. **绕过补录（M10 记录义务转移）**：领导口头插单可以，机制管不住行为但守住度量——任何人可在纪要补录"本周未走议价台的急件 N 件"。绕过率连续 2 班上升且送达率 <50% 同时出现 → 研发负责人有义务书面反馈（升级从人肉勇气变成规则触发）。

## 六、毒性信号与回退（Phase 2 专属清单）

触发即在该班纪要标记，Gate 2 复盘会裁决回退或修正：

- 让位出现**指派**（非自愿）——违反 H5，一票否决式记录；
- 加班车连续两班；
- 债务连续 2 班只借不还；
- 议价台流程使周五会延长超过 +15 分钟预算且无收敛迹象；
- 预测投票参与率 <50% 持续 2 班（降级为简单投票或撤下）；
- 急件审计三问连续 2 班无法完成（急件太多审不完 = "急"已通胀）。

**总回退原则**（沿用 Phase 1）：纸面流程全部是叠加层，下线 = 纪要不再记这些栏位，v1/v2.0 行为零损失。

## 八、每班采集清单（记录人对照填，喂 Gate 2）

纪要 Phase 2 栏位即采集表：急件数 / 走议价台件数 / 绕过补录件数、储备（配额-消耗-余额）、让位（件数-点数-自愿率）、债务（新增-偿还-余额）、保座兑现（上班保座件本班留存情况）、预测投票（参与人数-下注分布-命中名单）、治理耗时（分钟）。

## 九、Gate 2 待拍板的开放问题（4 班后复盘会用）

1. **工具化范围**（若通过）：`urgent_deals` 议价单表 / `carryReason` 加 `swap` 枚举 + 让位豁免逻辑（不递增 carryCount、归档只算 stranded、滞留率只算 stranded）/ 让步总账面板 / 预测投票数字版——做哪些、什么顺序；
2. **swap 存量回溯**：是否按 `swap：` note 前缀一次性回补纸面期数据；
3. **预测投票匿名强度**：纸条（开奖前保密）vs 公开举手 vs 工具化匿名；
4. **赌题定价**：固定 80% vs 发车时按装载浮动（如装载 > 昨日天气建议上限时自动上调赌题线）；
5. 预言家/让位贡献/无债一身轻三枚徽章（决议 4 预留）随工具化一并上还是分版。

## 附录 B · 话术包（照念即可）

- **领导周中插急件**："可以谈。给我十分钟，我把菜单列给您——储备、让位、借贷、加开，总有一条路，您挑一条。"
- **邀请让位**："本周有件急件需要腾 \_ 点，谁愿意换乘下一班？保座票 + 滞留豁免 + 让位点数记账。没人愿意也 OK，我们走借贷。"
- **周五急件审计**："这件急的：送达了吗？'为什么是现在'当时成立吗？现在回头看，值吗？一句话。"
- **发车段下注**："新车发出去了。老规矩：这班送达率到得了 80% 吗？写下你的答案，下周五见分晓。"
- **还债清单开场**："先还债。上一班我们借了 \_ 点给 \_\_\_\_，今天这班第一件事是把它装上。"
