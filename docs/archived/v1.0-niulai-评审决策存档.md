# v1.0「niulai」评审决策存档

> 本文档只保留评审的**最终结论**；问题明细与修复过程见 v1.0.0 tag 之前的 git 历史。

## 决策记录

- **第三次结转**：不做硬拦截，`carryCount >= 2` 仅触发强制复盘提示。
- **任务大厅**：「需求池」更名为任务大厅，条目是**委托**（需求在外部流程管理）；委托可编辑、可解除关联、三态由关联任务自动推导。
- **稀有度分级**：按 `docs/archived/任务大厅与稀有度分级设计方案.md` 执行，最终全部合入 v1.0。
- **稀有度拦截**：先实现过「神话不可上车」拦截，终审时明确解除——**稀有度只是标记，系统不拦截任何委托上车**；「神话必须切片」保留为发车会纪律。
- **班次模型**：「淡化周概念、单月多班车」最终合入 v1.0——班次由「发新车」手动创建，不绑定周五，字母 A–Z。
- **等量换出**：不进入工具，保留为发车会纪律。
